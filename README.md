# Goal Lit 앱 (PWA)
goal-lit.soulbound.co.kr의 공개 JSON 피드(`/api/feed.json`)를 읽는 가벼운 리더 앱이에요.
- 빌드 도구·외부 의존성 없음: 정적 파일만 (예: `python3 -m http.server 8000` 후 `http://localhost:8000` 접속)
- 스토어 제출 없음, 비밀값 없음
- 규칙: 필명 바이라인만, 글 본문은 사이트 링크로 연결(앱이 본문을 복제·수정하지 않음), 보라색 금지
- main 직접 푸시 금지, PR로만 변경

글 탭에는 제목, 필명, 날짜, 작품명, 요약을 표시하고 카드를 누르면 피드의 원문 URL로 이동해요. 작품 탭에서는 종류별로 목록을 골라볼 수 있어요. 탭은 방향키·Home·End로도 이동하며, 조작 영역은 최소 44px이에요.

HTTPS 또는 localhost에서 서비스 워커가 앱 파일과 목록 메타데이터를 저장해요. 피드는 네트워크를 먼저 확인하고, 오류·잘못된 응답·6초 지연 시 저장본을 사용해요. 마지막 정상 피드를 localStorage에도 저장해서 서비스 워커를 쓸 수 없을 때 복원해요. 저장된 데이터가 없는 첫 방문에는 연결이 필요해요. 글 본문은 가져오거나 저장하지 않으며, 원문을 읽으려면 연결이 필요해요.

다른 도메인에 배포할 때는 피드 서버의 CORS 허용이 필요해요. 앱 파일을 변경해 배포할 때는 `sw.js`의 `SHELL` 캐시 버전을 올려주세요. 앱과 목록 캐시만 정리하며 다른 앱의 캐시는 건드리지 않아요.
